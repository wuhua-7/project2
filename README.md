# 逐行顯示網頁

一個簡單的逐行顯示效果網頁，可以用來展示詩詞、公告或簡報內容。

## 部署到 Vercel

### 方法一：使用 Vercel CLI（推薦）

1. 安裝 Vercel CLI：
```bash
npm install -g vercel
```

2. 在專案目錄執行：
```bash
vercel
```

3. 按照提示操作即可完成部署

### 方法二：使用 GitHub + Vercel 網站

1. 將專案推送到 GitHub
2. 前往 [vercel.com](https://vercel.com)
3. 點擊「Import Project」
4. 選擇你的 GitHub 倉庫
5. 點擊「Deploy」

## 本地預覽

直接用瀏覽器開啟 `index.html` 即可。

## 自訂內容

編輯 `index.html` 中的 `lines` 陣列來修改顯示的內容。
