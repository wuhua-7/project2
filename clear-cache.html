🧹 清除瀏覽器緩存

自動清除項目：

  • localStorage
  • sessionStorage
  • IndexedDB
  • Service Workers
  • Cache Storage

手動清除步驟：

  1. 按 Ctrl + Shift + Delete (Windows) 或 Cmd + Shift + Delete (Mac)
  2. 選擇「所有時間」
  3. 勾選：
    • 瀏覽記錄
    • Cookie 和其他網站數據
    • 快取的圖片和文件
  4. 點擊「清除數據」
  5. 重新載入頁面（Ctrl + F5 或 Cmd + Shift + R）
